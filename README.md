## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

This project is a complex iOS application to measure and analyze the performance of athletes. In a sense, this app utilize iPhone camera and LiDAR to capture your workout session, then use the data to track and analyze every movement you made. It includes features such as:
- **Pose Tracking**: Record and analyze sport sessions.
- **Performance Metrics**: Measure various performance metrics such as body angles.
- **Realtime and Offline Tracking**: Track performance in real-time or offline mode.
